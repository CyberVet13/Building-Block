# Market Analysis Template

## Sections

### 1. Industry overview

- Current market size and growth rate (CAGR)
- Key trends shaping the space (regulatory, technology, behavior)
- Market maturity stage

### 2. Target customer segments

Define 2–3 segments with:

- Demographics / firmographics
- Jobs-to-be-done
- Willingness to pay
- Acquisition channels

### 3. TAM / SAM / SOM

| Level | Definition | Estimate | Method |
|-------|------------|----------|--------|
| TAM | Total addressable | | Top-down or bottom-up |
| SAM | Serviceable | | Geographic + segment filter |
| SOM | Obtainable (3 yr) | | Realistic share % |

### 4. Customer pain validation

- Primary research (interviews, surveys)
- Secondary data sources
- Quotes or paraphrased insights

### 5. Market entry timing

Why now? What changed to make this opportunity viable?

## Retrieval hints

Pull industry-specific benchmarks when `industry` is set. Prefer recent sources (last 3 years).
